# Baly Driver Assistant

تطبيق Android مساعد لتحليل ربح طلبات التوصيل، مع واجهة عربية RTL ومحرك حسابات تقديري.

## بناء APK عبر Codemagic
1. اربط مستودع `Younishbh/Ynis3` بحسابك في [Codemagic](https://codemagic.io/).
2. اختر البناء باستخدام ملف الإعداد `codemagic.yaml` الموجود في جذر المستودع.
3. شغّل workflow باسم **Baly Driver Assistant - APK**.
4. بعد نجاح البناء، افتح صفحة الـ build في Codemagic ونزّل `app-debug.apk` من قسم **Artifacts**.

هذا workflow ينتج APK تجريبيًا موقّعًا بمفتاح debug، مناسبًا للتثبيت والاختبار. للنشر العام على Google Play أو التوزيع الإنتاجي، أنشئ إعداد توقيع release خاصًا بك واحفظ مفاتيحه في Codemagic secure environment variables / code signing، ولا تضع keystore أو كلمات مروره في المستودع.

## ما يعمل في النسخة الحالية
- واجهة عربية متوافقة مع RTL.
- إدخال الأجرة والمسافة الإجمالية والمدة واستهلاك الوقود والأسعار والتكاليف.
- حساب الوقود وصافي الربح والربح لكل كيلومتر وساعة.
- توصية قبول/متوسط/رفض قابلة للتأثر بحدود الربح والمسافة المدخلة.
- جميع الحسابات محلية على الجهاز.

## ما لم يكتمل بعد
هذه النسخة الأولية لا تتضمن بعد Room والإحصائيات، OCR/MediaProjection، خدمة خلفية أو نافذة عائمة. لا توجد واجهة رسمية لـ Baly مستخدمة هنا؛ قراءة الشاشة مستقبلًا ستتطلب موافقة صريحة من المستخدم، ويظل أي قرار قبول أو رفض يدويًا.

## المتطلبات
Android Studio حديث وJDK 17. الحد الأدنى Android 8.0 (API 26)، وهدف البناء API 35.
