# Baly Driver Assistant

تطبيق مساعد للسائقين لتحليل طلبات التوصيل محليًا عبر OCR أو MediaProjection، مع واجهة عائمة قابلة للتحريك ولوحة إعدادات وإحصائيات محفوظة داخل Room.

## الخصوصية
- لا يجمع التطبيق كلمات مرور أو بيانات حساب Baly.
- لا يرسل صور الشاشة أو البيانات إلى خوادم خارجية.
- لا يستخدم Accessibility Service أو يضغط على أزرار القبول والرفض.
- قرار القبول يبقى للسائق دائمًا.

## الصلاحيات
- `FOREGROUND_SERVICE`: لتشغيل خدمة capture عند طلب المستخدم.
- `FOREGROUND_SERVICE_MEDIA_PROJECTION`: لخدمة MediaProjection على Android الحديث.
- `SYSTEM_ALERT_WINDOW`: لإظهار النافذة العائمة فوق التطبيقات.
- `POST_NOTIFICATIONS`: للإشعار المطلوب للخدمة الأمامية.

## تشغيل المشروع
1. افتح المجلد في Android Studio.
2. نفّذ Gradle Sync.
3. شغّله على Android 8.0 أو أحدث.
4. فعّل صلاحية النافذة العائمة وابدأ الالتقاط.

## القيود
قراءة نصوص واجهة Baly تعتمد على تنسيق الشاشة والنسخة المثبتة؛ لا يوفر تطبيق Baly واجهة رسمية في هذا المشروع. عند فشل OCR يمكن إدخال تفاصيل الطلب يدويًا.
